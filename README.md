# Shrey Jain

Computer Engineering student at McGill University, with a minor in Applied AI.

I build mobile apps, AI tools, and multiplayer games. I founded Velrey Development and work on LiDAR perception with McGill Formula Electric's driverless subteam.

## Projects

- **[LifeLayer](https://github.com/shreysprojects/lifelayer):** a productivity app that combines routines, fitness, nutrition, and cloud sync. I'm building it with ADHD in mind and using it as I prepare for an App Store launch. The [app code](https://github.com/shreysprojects/ProductivityNative-) uses React Native, Expo, and Supabase.
- **[TimeLog](https://github.com/shreysprojects/TimeLog) and [HabitLog](https://github.com/shreysprojects/HabitLog):** smaller apps for managing time and daily habits.
- **[AI-Intelekt tools](https://github.com/shreysprojects/intellect-projects):** service-record analysis, translation and writing-correction APIs, and Jira automation from my summer 2026 internship. I also built a [content pipeline](https://github.com/shreysprojects/ai-intelekt-engine) with fact-checking and human approval.
- **[Roblox games](https://github.com/shreysprojects/roblox-games):** multiplayer games reaching roughly 1,000 concurrent players. I also led core scripting on a team that placed first at a McGill GameDev Club game jam.
- **[Unity](https://github.com/shreysprojects/Rollaball) and [Blender tools](https://github.com/shreysprojects/BlenderExports):** game projects and a Blender-to-Roblox asset pipeline.

Other work includes an Arduino obstacle-avoiding car, converting MATLAB workflows to Maple at Metallurgical Sensors, and browser automation tools.
